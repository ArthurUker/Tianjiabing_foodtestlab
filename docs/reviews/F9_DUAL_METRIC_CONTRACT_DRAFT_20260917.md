# F9 · 双指标契约草案（初检口径 / 最终结论口径）— **草案，未实现、未发布**

> 背景：`/stats` 现有合格率按**初检**判定（v1 语义，`metric_basis='initial_conclusion'`），
> 与明细的 `final_conclusion`（有复检时取复检结论）可能不同（例：初检不合格 → 复检合格 → 明细 pass，但未计入 `pass_count`）。
> 本文**不改动** v1 指标含义，只给"若业务需要最终结论口径"的契约设计与待确认项。

## 1. 两套指标的分子/分母定义（建议）

| 维度 | 初检口径（现有 `pass_rate`） | 最终结论口径（建议新增 `pass_rate_final`） |
|---|---|---|
| 分子 | `initial_conclusion = pass` 的记录数 | `final_conclusion = pass` 的记录数 |
| 分母 | `scope_total`（日期合法 ∧ 授权内 ∧ 请求内） | 同一 `scope_total`（**分母保持一致**，便于对照） |
| `possible`（提案） | `initial_conclusion = fail` | `final_conclusion = fail` |
| 未知处理 | `unknown` **仍计入分母**（v1 不变） | 同 v1（计入分母），另给 `unknown_count` 便于解释 |
| `warning`（警戒） | 按现有判定（危险等级见各类型口径），不计入 pass | 同左 |
| 零分母 | `null`（不返回 0） | `null` |
| 日期缺失/非法 | 进 `excluded_total`，不进任何分母 | 同左 |

**并存的表述要求**：两个字段必须互相声明（`metric_basis` / `metric_basis_note`），接入包给出对照示例，避免被混用。

## 2. 复检计数规则（关键：一条记录不得变成多条）

1. 统计单位 = **检测记录**（不是复检次数）：同一条记录即使复检 3 次，仍只贡献 1 个分子/分母单位。
2. 复检结论取值 = **最新一次**复检（`recheckRecords[0]` / `recheckReports[0]`，与 `getLatestRecheckPassed` 一致）；
   若结构未知/`isPassed` 非布尔 → 该记录按 `unknown`（不猜测）。
3. 需要"复检次数"类指标时，另设显式字段（如 `recheck_rounds_total`），不混入合格率。

## 3. 时间归属（需业务确认）

| 方案 | 含义 | 影响 |
|---|---|---|
| **A. 按原检测日期归属（建议）** | 记录的 `test_date` 决定它落在哪个月；复检只改结论 | 与现有 `/stats` 的 `test_date` 过滤一致；历史月份数字会随复检**变化** |
| B. 按复检日期归属 | 复检完成后计入复检当月 | 需要额外的"复检完成时间"字段；历史月份数字不再变化，但与明细 `test_date` 不一致 |

**需业务确认**：① 取 A 还是 B；② 若取 A，"历史月份的最终合格率会被后续复检改写"是否可接受；
③ 是否需要"截至某时点的快照"（避免历史数字漂移）——这需要额外的快照表，成本较高，默认不做。

## 4. 与"重判历史"的边界（必须写清）

- ✅ 允许：**重新汇总已保存的结论**（`conclusion`/`final_conclusion` 是录入时冻结值，重汇总只是换口径统计）。
- ❌ 不允许（除非业务明确批准）：**用新阈值重判历史原值**（例如拿 `tpmValue` 按新阈值重算历史合格/不合格）。
- 二者必须在文档与字段命名上区分（建议新字段名带 `_final`，并在 note 中写明"基于已保存结论，不含阈值重判"）。

## 5. by_type 结构与迁移

- `by_type[]` 每项同时给 `pass_rate`（初检）与 `pass_rate_final`（最终）+ 各自 `pass_count`/`pass_rate_detail`；
- 顶层 `pass_rate` 保持 v1 语义不变（**不改**）；新增 `pass_rate_final` 为追加字段；
- 兼容策略：老客户端忽略新字段即可；接入包给出"对账示例"（初检 40% vs 最终 60% 的同一批数据）；
- 若最终决定**不提供**最终口径：则在文档中明确"本平台指标为初检口径"，并保留 `metric_basis` 声明。

## 6. 仍需业务确认项（最少集）

1. 是否需要最终结论口径（若否，本草案归档为"设计备选"）。
2. 时间归属取 A 还是 B（§3）。
3. 历史月份数字可被复检改写是否可接受。
4. `unknown` 是否继续计入分母（v1 现状=计入；若改需另立条款）。
5. 字段命名（`pass_rate_final` 是否可接受）。
