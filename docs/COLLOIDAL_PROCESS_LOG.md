## 操作入口

拍照或上传识别后，点位下出现“拍照与算法识别过程日志”。展开后可查看每一次尝试、刷新进度和下载JSON。三次采样逐张记录。失败后无需保存合格／不合格即可查看日志；刷新页面可用“恢复上次未完成的照片录入”。最终记录详情中的“原始照片与结果录入过程”也可展开同一日志，权限沿用现有记录访问控制。

单次拍照与自动采样相机预览增加左／右旋转90°、左右镜像、上下翻转、复位。完整画面以contain方式显示，旋转时自适应尺寸，避免裁掉定位码。**这些设置只改变预览显示，上传／保存／识别仍使用相机原始帧**。每次快门日志记录实际分辨率和当时的预览设置。系统相机回退入口受设备原生界面控制，不能提供网页预览按钮。

## 日志内容和判断边界

| 阶段 | 保存的诊断内容 |
|---|---|
| 相机／选图 | 请求相机、预览就绪、开始采样、取得帧／文件、宽高、字节数、预览旋转／镜像；浏览器来源明确标记 |
| 上传／队列 | 服务端登记、开始接收请求体、原图保存及SHA256、持久化耗时、排队及分派等待时间、重试或服务错误 |
| 解码 | 文件格式、原始尺寸、EXIF方向、方向处理后尺寸、解码失败 |
| 板／单卡几何 | 输入模式、定位标记ID、内点数、误差与门限、布局版本、卡位原图坐标；单卡方向旋转信息 |
| 窗口搜索 | 边缘候选数和中心、轮廓补救有无匹配、是否启用扩展搜索、窗口选择／失败、最终窗口及实际测量区域原图坐标 |
| C/T测量 | 通道、C/T信号、C线存在阈值、噪声、拟合位置／次数、测量线原图坐标、曝光截断检查结果 |
| 候选与旁路 | 图像候选；原核心RGB／学习诊断旁路的执行状态，明确不接管主判读 |
| 业务判定 | 时间来源、各通道时间有效性、图像／最终候选、能否自动保存、算法／补丁版本、失败原因 |

“几何通过”“轮廓匹配”仅说明当前算法接受了位置，**不证明真实膜窗和色带被准确覆盖**。坐标统一为EXIF处理后的原图像素坐标；卡位坐标另行标注，不能混用。坐标和信号可用于定位问题，不自动认定实体卡失效。

设备时间与服务器时间分开显示，不用跨设备时钟相减推算网络耗时。服务端photo_stored的persistence_ms从请求体解析完成后开始计时，仅代表存储处理；排队时间在Node同一时钟内计算；算法累计时间使用Python单调时钟。照片文件选择时间不当成历史照片拍摄时间。普通单次入口仍沿用既有within_window明确假定，三次采样使用实测时距。

日志由独立适配器观察固定核心函数的原始返回，不更改几何、像素和判读；每次识别结束恢复函数引用。日志保存到租户ColloidalAttempt.process_log，最多256条；客户端只允许16条白名单采集事件，标记browser，不接受伪造算法事件。服务器内部日志最多160条，只含有界文字／数值／坐标。不写像素、信号曲线、裁剪图、标线图或文件路径；原图留存方案与保留期不变。历史记录不补造当时不存在的日志；旧Python适配器会显示“内部日志不可用”。算法日志在本次计算结束时汇总入库，运行中可看到登记、上传与排队状态，无法把进程崩溃前未返回的内部步骤伪装成已记录。

## 同局域网测试

独立本地环境已增加[免密码入口与重启说明](COLLOIDAL_LOCAL_NO_PASSWORD.md)：启用专用本地preload后，原测试登录网址自动进入。此选项仅用于隔离测试，不随服务器部署启用。

独立测试后端仍只监听127.0.0.1；`scripts/colloidal-lan-preview.mjs`在指定私有网卡上提供HTTPS反向代理和单独的HTTP证书说明页，不开数据库端口、不建公网隧道。运行示例：

```sh
node scripts/colloidal-lan-preview.mjs --host <本机局域网IPv4> --runtime-dir .cache/colloidal-local-trial-20261022/lan-tls
```

默认后端55539、HTTPS55543、证书设置页55538。本地试用学校入口`/reader-local-1022/login.html`。启动后把HTTPS来源加入**本地测试后端**CORS白名单，保留原本回环来源。证书／私钥只生成到忽略的.cache，不提交Git，不自动安装到任何设备信任库。根证书有效30天；参与测试设备手动安装并信任，结束后可移除。私钥绝不提供下载。IP改变后以新IP重启代理、更新本地CORS；已有CA保留，不必重复安装根证书。

iPhone：下载CER后到“设置→通用→VPN与设备管理”安装，再到“通用→关于本机→证书信任设置”完全信任该测试根证书。[Apple说明](https://support.apple.com/zh-cn/102390)。安卓／电脑需在各自证书管理界面安装到受信任根；厂商菜单不同。普通局域网HTTP不满足网页相机的安全上下文要求，[MDN说明](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)。未信任证书时不能把证书警告页当成相机验收通过。
