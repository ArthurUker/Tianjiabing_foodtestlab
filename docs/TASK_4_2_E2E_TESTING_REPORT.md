### 自定义命令 (支持/e2e.js)

```javascript
// 登录命令
Cypress.Commands.add('login', (email, password) => {
  cy.get('input[type="email"]').type(email);
  cy.get('input[type="password"]').type(password);
  cy.contains('button', /登录/).click();
  cy.url().should('not.include', 'login');
});

// 创建记录命令
Cypress.Commands.add('createTestRecord', (data) => {
  cy.get('[data-testid="create-button"]').click();
  Object.entries(data).forEach(([key, value]) => {
    cy.get(`[data-testid="input-${key}"]`).type(value);
  });
  cy.get('[data-testid="submit-button"]').click();
});

// 检查通知命令
Cypress.Commands.add('checkNotification', (message, type = 'success') => {
  cy.get(`[data-testid="notification-${type}"]`)
    .should('contain', message);
});
```

## 🚀 运行 E2E 测试

### 快速开始

```bash
# 打开 Cypress 交互式界面
npm run test:e2e:open

# 运行所有 E2E 测试
npm run test:e2e

# 运行无头模式
npm run test:e2e:headless

# 生成测试报告
npm run test:e2e:report

# 运行全部测试（单元 + E2E）
npm run test:all
```

### 运行特定测试

```bash
# 运行特定测试文件
npx cypress run --spec "cypress/e2e/auth.cy.js"

# 运行匹配的测试
npx cypress run --spec "cypress/e2e/**/offline.cy.js"

# 调试模式
npx cypress open --e2e
```
