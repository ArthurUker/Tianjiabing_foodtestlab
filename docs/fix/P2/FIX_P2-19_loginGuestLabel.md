## 1. 问题描述

`login.html` 访客/快速访问按钮的描述文字与访客实际权限范围不一致，误导用户对访客能力范围的认知（如暗示访客可查看所有模块，但实际病原体模块对访客不可见）。

## 2. 根因分析

P0-07 修复后，快速访问模式改为后端签发只读限权 JWT；P1-18 进一步收紧访客不可访问病原体模块。但 `login.html` 访客按钮的描述文字未同步更新，仍保留早期宽松权限的表述。

## 3. 修复方案（2026-07-04 实施）

更新访客按钮描述，明确权限边界：

```html
<p class="text-gray-700 font-medium mb-1">访客只读模式</p>
<p class="text-gray-500 text-sm">可查看餐具、农残、食用油等检测数据，无法新增或修改，病原体检测模块不可见</p>
```

明确三点：①可查看的模块范围；②不可新增/修改（只读）；③病原体模块不可见。
