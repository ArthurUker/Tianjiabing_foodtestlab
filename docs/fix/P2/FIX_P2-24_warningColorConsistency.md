## 1. 问题描述

`GenericTest.js` 食用油模块的"警戒"等级记录在列表 `render()` 与详情弹窗 `showDetailModal` 颜色展示不一致：
- 列表 `render()`（原 L1114 `const isPass = result === '合格'` / L1145 二元红绿）对"警戒"记录显示为红色；
- 详情弹窗 `showDetailModal`（L526 三元 合格绿/警戒黄/不合格红）显示为黄色。

同一记录两处颜色不一致，误导用户。

## 2. 根因分析

列表渲染采用二元判定（合格=绿，其余=红），未识别"警戒"中间态；详情弹窗采用三元判定。经全文件 `grep "警戒"` 交叉验证，5 处命中（L526/L596/L598/L599/L632）均落在食用油模块 `getAcidLevel`/`getTpmLevel`/`getWorstLevel`/`recomputeOilFinalQuality` 及调用链内，仅影响食用油模块（农药残留/肉蛋农残仅合格/不合格二元结果，无"警戒"等级）。

## 3. 修复方案（2026-07-04 实施）

列表 `render()` 改为三元判定，与详情弹窗一致：

```javascript
// P2-24: 列表颜色改为三元判定（合格绿/警戒黄/不合格红），与详情弹窗 showDetailModal 一致
: result === '警戒' ? 'bg-yellow-100 text-yellow-800'
```
