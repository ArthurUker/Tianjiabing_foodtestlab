## 1. 问题描述

`docs/API_REFERENCE.md` 文档头部元信息与一处理故障排查条目仍记录田家炳系统遗留端口 `3001`/`8081`，与珠海一中生产实际端口 `3002`/`8082` 不符。文档正文（Nginx 反向代理说明、调试示例、PowerShell 示例）此前已为 `3002`/`8082`，导致文档头部与正文内部不一致。核实发现的错误位置（修复前）：

| 行号 | 内容 | 实际值 |
|------|------|------|
| L8 | `**默认后端端口**：`3001`` | `3002` |
| L9 | `**生产访问端口**：`8081`，由 Nginx 反向代理至后端 `/api`` | `8082` |
| L47 | `| 默认端口 | `3001` |` | `3002` |
| L1857 | `2. 后端端口不是 `3001`；`（19.8 502 Bad Gateway 排查） | `3002` |

## 2. 根因分析

项目由"田家炳食品检验系统"（foodtestlab，端口 `8081`/`3001`）衍生为"珠海一中食品检验系统"（zhuhaiyizhong，端口 `8082`/`3002`）时，`API_REFERENCE.md` 在 v1.1 收敛时仅更新了正文示例端口，遗漏了文档头部元信息（L8/L9）、基本信息表（L47）与 19.8 故障排查条目（L1857），属端口迁移不彻底。生产实际端口以 `deploy.ps1` 为权威来源：L104-105 `$frontendPort = 8082` / `$apiPort = 3002`，L500-521 Nginx `listen 8082` → `proxy_pass http://127.0.0.1:3002`；`backend/server.js` L29 `const PORT = process.env.PORT || 3002`。

## 3. 修复方案

### 方案 A（推荐，已采用）

将 4 处错误端口替换为核实后的真实端口：

```diff
  L8:  - **默认后端端口**：`3001`
  L8:  + **默认后端端口**：`3002`

  L9:  - **生产访问端口**：`8081`，由 Nginx 反向代理至后端 `/api`
  L9:  + **生产访问端口**：`8082`，由 Nginx 反向代理至后端 `/api`

  L47: - | 默认端口 | `3001` |
  L47: + | 默认端口 | `3002` |

  L1857: - 2. 后端端口不是 `3001`；
  L1857: + 2. 后端端口不是 `3002`；
```
