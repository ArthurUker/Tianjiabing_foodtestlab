## 一、BK-R1核对：全部恢复后，各校表行数与备份 meta 一致

> 前置：浏览器已完成 BK-D1（各校录入 BKTEST）→ BK-D2（全库备份）→ BK-D3（BKTEST2）→ BK-R1（逐校全部恢复）。
> 目标：证明「全部恢复后各校数据 == 备份时刻数据」。

### 1. 取全库备份 meta.json 的表计数基线

```bash
# 列出最近的备份文件
sudo ls -lt /var/backups/foodtestlab/*/all-databases.*.meta.json | head -3

# 取最新一条 meta 的路径（记下 META=）
META=$(sudo ls -t /var/backups/foodtestlab/*/all-databases.*.meta.json | head -1)
echo "META=$META"
sudo cat "$META" | python3 -c "import json,sys; m=json.load(sys.stdin); tc=m.get('tableCounts',{}); [print(k, '=', v) for k,v in tc.items() if k.startswith('school_') and k.endswith('.TestResult')]"
```

> 这一步输出各校 `school_<code>.TestResult = <行数>` 的**备份时基线**，记录下来。

### 2. 查询恢复后各校实际行数

```bash
for s in school_tjb school_dmyz school_hqyz school_shiyan school_zhyz; do
  echo "== $s =="
  sudo -u postgres psql -d foodtestlab -t -A -c "SELECT count(*) FROM \"$s\".\"TestResult\";"
  # 抽查其它板块表
  for t in TestRecord TestItem Tableware Guest; do
    sudo -u postgres psql -d foodtestlab -t -A -c "SELECT count(*) FROM \"$s\".\"$t\";" | sed "s/^/  $t=/"
  done
done
```

### 3. 比对判定

| 项 | 判定 |
|---|---|
| 5 所学校 `TestResult` 行数 == 第1步基线 | ✅ 通过（全部恢复数据回滚成功） |
| 任一差异 > 0 | ❌ 失败，记录差异值，联系开发 |

> 提示：也可全局对比 BKTEST 标记数据是否清空（恢复前 BK-D3 录入的 BKTEST2 应消失）：
```bash
sudo -u postgres psql -d foodtestlab -t -A -c "SELECT count(*) FROM school_tjb.\"TestRecord\" WHERE 备注字段 ILIKE '%BKTEST2%';"
```
> 具体字段名以学校表结构为准（TestRecord 的说明/备注列），此处为示意。

## 二、BK-I1核对：学校侧恢复后，他校行数未变

> 前置：浏览器已用 dmyz manager 在本校界面用全库备份恢复 dmyz。
> 目标：证明「dmyz 回滚 + tjb/hqyz/shiyan/zhyz 数据零影响」。

### 1.（应在浏览器操作前）先取 4 个观察校基线

```bash

  sudo -u postgres psql -d foodtestlab -t -A -c "SELECT count(*) FROM \"$s\".\"TestResult\";"
done
```

### 2.（浏览器操作完成后）再取同样 4 校 + dmyz

```bash
for s in school_tjb school_dmyz school_hqyz school_shiyan school_zhyz; do
  echo "== $s (恢复后) =="
  sudo -u postgres psql -d foodtestlab -t -A -c "SELECT count(*) FROM \"$s\".\"TestResult\";"
done
```

### 3. 判定

| 项 | 判定 |
|---|---|
| tjb/hqyz/shiyan/zhyz 行数【前后一致】 | ✅ 隔离有效 |
| dmyz 行数【回退到备份时值】 | ✅ 恢复生效 |
| 任一观察校行数变化 | ❌ 隔离失效（严重），联系开发 |
