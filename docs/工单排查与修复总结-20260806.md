## 六、附录:排查方法论教训(高频误判清单)

> 收录自实际排查事故,详见 README §12.6。核心 4 条:

1. **Caddy `rewrite` ≠ HTTP 重定向**:服务端内部 URI 转发,不改浏览器地址栏 URL,返回 200 无 `Location` 头。排查路径前缀问题时先 `curl -I` 确认有无 Location。
2. **grep 找不到路由 ≠ 路由不存在**:路由可能用变量拼接、挂前缀、分散多文件。grep 空时扩大搜索范围并试参数化路由名(曾误判 `/api/records/:type` 404)。
3. **`$queryRawUnsafe` 返回 JSONB 列是字符串**:需 `JSON.parse` 后再消费,前端读取配置时外层与内层 JSON 字段分别 parse。
4. **systemd `Restart=on-failure` 自动拉起**:kill 手动进程后 systemd 5 秒内重启并重新占端口。排查端口占用先 `systemctl status`,部署统一 `systemctl restart`。
