验证

verify

对备份文件的完整性 + 解密可行性做只读校验：解密 header、检查 schema 转储和 media 文件存在、比对 tar 包大小与头部记录是否一致。

何时用：恢复前必做（确保备份可读）；定期巡检（凌晨备份后人工抽样）。

零风险，不修改任何数据。

AES（加密）下载

encrypted

下载包含 AES-256-GCM 信封加密的 tar 包（密钥派生自全局 secret）。文件可被异地备份服务导入。

何时用：异地归档、长期保留、需要保密物理介质的场景。

解密需要服务端 secret；丢 secret = 永久无法恢复。

明文下载

plain

已解密的 tar.gz（含 schema_dumps.sql + media/）。可直接 tar -tzf 浏览结构、grep 业务数据、离线分析。

何时用：诊断具体某学校的表数据、研发核对业务逻辑、应急抢救单一记录。

含敏感数据，离线存储需相应加密措施。

影子恢复

restore

把当前 school_<code> schema 重命名成 school_<code>_old_<ts> 暂存，再用目标备份新建同名 schema、写回数据。

何时用：误删数据回滚 / 学校迁移 / 灾难恢复。

不可逆操作（写入数据库），需输入 RESTORE 二次确认。
